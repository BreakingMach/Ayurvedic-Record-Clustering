# SYNTHETIC/SIMULATED Mixed-Type Cohort Datasheet (`docs/SYNTH_DATASHEET.md`)

> **WARNING (Rule R4):** Every cohort generated by `python_benchmark/ayur_bench/synth/generator.py` (including `Dataset/synthetic/synthetic_cases_default.csv`) is **SYNTHETIC/SIMULATED**. The `latent_class` column is **simulation ground truth by construction**, NOT a practitioner-assigned diagnosis. All experimental findings from this generator describe the behaviour of distance metrics on the **synthetic data-generating process**, not on real Ayurvedic patients.

---

## 1. Purpose & Intended Use
- **Why a synthetic benchmark is needed:** The real dataset (`Dataset/tridosha.zip` / `Updated_Prakriti_With_Features.csv`) contains **29 categorical traits and 0 numeric columns**. As proven in Experiment A (`docs/REAL_DATA_FINDINGS.md`), Gower, Euclidean (one-hot), Cosine (one-hot), and Hamming have `Spearman ρ = 1.000000` on categorical-only data. To meaningfully benchmark mixed categorical–numerical distance behaviour (skewed numerics, uninformative numeric covariates, correlated vitals, numeric outliers, missing values, and label noise), a controlled synthetic mixed-type generator is required.
- **Intended use:** Controlled stress-testing of Gower, Euclidean (z-scored + one-hot), and Cosine (z-scored + one-hot) distances under explicit, reproducible regimes frozen in `python_benchmark/ayur_bench/config.yaml` before observing results (Rule R3).
- **Out-of-scope / prohibited use:** Do **not** use synthetic cohorts for clinical decision-making, medical training, or claims about real Ayurvedic epidemiology or practitioner concordance.

---

## 2. Generative Specification

### 2.1 Latent Class Sampling (`latent_class`)
- Default sample size `N = 1200`, matching exact empirical class proportions from `Updated_Prakriti_With_Features.csv`:
  - `Vata+Pitta`: 52.0% (`624 / 1200`)
  - `Vata`: 22.0% (`264 / 1200`)
  - `Pitta`: 12.0% (`144 / 1200`)
  - `Kapha`: 6.0% (`72 / 1200`)
  - `Pitta+Kapha`: 4.0% (`48 / 1200`)
  - `Vata+Kapha`: 4.0% (`48 / 1200`)
- Rows are randomly permuted using the configured RNG so records are never ordered or blocked by class.

### 2.2 Categorical Traits (29 Columns)
- Exact same 29 trait column names and sorted level sets as `Updated_Prakriti_With_Features.csv`.
- Empirical conditional distributions $P(\ell \mid c, t)$ are estimated from the real CSV.
- Each trait value is sampled from the $\varepsilon$-smoothed mixture:
  $$P_{\varepsilon}(\ell \mid c, t) = (1 - \varepsilon)\, P(\ell \mid c, t) + \varepsilon \cdot \text{Uniform}(\text{levels}_t)$$

### 2.3 Continuous Numeric Vitals (4 Columns)
- **`age` (deliberately uninformative):** Always generated with Cohen's $d = 0$ independently of `latent_class`, from $\mathcal{N}(42.0, 12.0^2)$ clipped to `[18.0, 80.0]`.
- **`bmi`, `systolic_bp`, `pulse`:**
  - Each vital draws its own independent **randomised permutation** of the 6 classes, explicitly constrained NOT to match alphabetical order, reverse-alphabetical order, or canonical class order — **never** computed from label-index arithmetic (`y * c`).
  - Centered class offsets $r \in \{-2.5, -1.5, -0.5, +0.5, +1.5, +2.5\}$ are scaled by $0.5 \cdot d \cdot \sigma_{\text{within}}$, where $d$ is the configured Cohen's $d$ separation parameter.
  - **`bmi`** is **lognormal-skewed** (`log_mean = 3.12`, `log_std = 0.13`, clipped to `[14.0, 55.0]`).
  - **`systolic_bp`** is Gaussian (`mean = 120.0`, `std = 11.0`, clipped to `[80.0, 220.0]`).
  - **`bmi` and `systolic_bp` within-class correlation:** Coupled via a bivariate **Gaussian copula** with target correlation $\rho = 0.40$ on the latent normal innovations $(Z_{\text{bmi}}, Z_{\text{sbp}})$.
  - **`pulse`** is Gaussian (`mean = 74.0`, `std = 7.5`, clipped to `[45.0, 130.0]`) with an independent standard normal innovation.

### 2.4 Controlled Messiness Toggles
- **Outliers (`outlier_fraction`):** Independently per numeric column, replaces `round(outlier_fraction * N)` entries with `median ± 6 * std` (floored at `1.0`).
- **Missingness (`missing_fraction`):** Independently sets numeric (`NaN`) and categorical (`pd.NA`) cells missing completely at random with probability `missing_fraction`.
- **Label noise (`label_noise_rate`):** Applied **only** to `eval_label` (flipping each selected row uniformly to one of the other 5 classes). `latent_class` is never modified.

## 5. Key Limitations
1. **Generator-bound findings:** Any performance difference between Gower, Euclidean, and Cosine observed on synthetic cohorts reflects the assumed generative model (4 continuous vitals + 29 categoricals, lognormal BMI, Gaussian copula, `±6σ` outliers), not real clinical populations.
2. **Independence across categorical traits given class:** Categorical traits are sampled conditionally independently given `latent_class`, ignoring higher-order inter-trait interactions that may exist in real patients.
3. **Latent class is not clinical truth:** `latent_class` exists by construction of the simulator and inherits the unverified class proportions of the public Kaggle CSV.
