# Clinical Similarity Rating Instructions (2-Minute Guide)

Thank you for helping evaluate patient-profile similarity on real Ayurvedic questionnaire records.

## What You Are Reviewing
- Open **`rating_sheet.xlsx`** (sheet **`Rating_Sheet`**).
- There are **40 de-identified patient queries** (`Q01` through `Q40`).
- Each query is paired with **5 candidate records** (`A` through `E`), shown in a **randomised order** (`200` pairs total).
- No algorithm names, similarity scores, ranks, or diagnostic labels are shown.
- For quick reading, columns **`query_differing_traits`** and **`candidate_differing_traits`** highlight only the traits where the query and candidate differ. You can view all 29 recorded traits for any profile on the second tab (**`Full_29_Traits`**).

## How to Rate Each Pair
Fill in column **`clinical_similarity_1_to_5`** using the scale below, based on your clinical judgement of how similar the two patient profiles are overall:

| Rating | Meaning |
| :---: | :--- |
| **1** | **Not similar at all** — clearly distinct clinical presentations / constitutional profiles |
| **2** | **Slightly similar** — few clinically meaningful traits in common |
| **3** | **Moderately similar** — mixed overlap; some shared core features, notable differences |
| **4** | **Quite similar** — closely aligned presentation with only minor clinical differences |
| **5** | **Very similar / clinically interchangeable** — nearly identical constitutional profile |

- **Comments (optional):** Use column **`comments`** to note any specific traits that drove your decision (for example, conflicting skin/digestion markers or traits that seem clinically contradictory).
- **No right or wrong answers:** Please rate purely on clinical judgement; do not try to infer any hidden ranking.

## When Finished
1. Save **`rating_sheet.xlsx`** (keep the `pair_id` column unchanged).
2. Return the saved file to the study coordinator. (If multiple reviewers participate, please rename your copy e.g. `rating_sheet_reviewer1.xlsx`.)
